# The Lionesses Effect: Growth of Women's Football in England

## Project Overview

This project investigates how public interest in women's football in England has changed over time, focusing on the commercial implications of major international tournaments.

Using Google Trends data and Python, the analysis explores whether events such as England's victory at UEFA Women's Euro 2022 produced sustained growth in interest.

## Research Questions

- How has search interest in the Lionesses changed over time?
- Did Euro 2022 create a lasting increase in interest?
- What might these trends suggest about the commercial opportunities in women's football?

## Data Sources

- Google Trends — UK search interest for "Lionesses"

## Tools

Python, pandas, Matplotlib and Jupyter Notebook.
